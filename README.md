## Purpose
Track the **best three useful tech-content examples** across:
1. **YouTube videos** — long-form tutorials, walkthroughs, explainers, and project builds.
2. **YouTube Shorts** — concise vertical explainers, quick demos, and coding/AI tips.
3. **Instagram Reels** — short-form tech explainers, creator-led demos, and practical tool showcases.

Topics must stay within technology and IT: AI, coding, software engineering, data engineering, cybersecurity, cloud, developer tools, databases, and tech careers. The goal is to learn content craft and make original work—not copy another creator.

## Daily entry format
Keep each example to approximately **2–3 compact lines**. Use the fields below in this order; include clickable source links.

```text
Date | Platform | Trend + evidence | Content format | Opening hook | Editing style | What makes it work | Content idea | Source
```

- **Date:** date researched (not just the date the original post was published).
- **Platform:** YouTube Video, YouTube Short, or Instagram Reel.
- **Trend + evidence:** topic plus observable signals (publication date, views, likes, comments, repeated appearances, or a credible trend report). Never invent metrics.
- **Content format:** tutorial, screen-recorded demo, comparison, story, experiment, etc.
- **Opening hook:** quote the exact opening only if verifiable; otherwise label it “paraphrase.”
- **Editing style:** minimal and simple; prioritize readable captions, clean audio, clear screen recording, and basic cuts.
- **What makes it work:** distinguish visible facts from hypotheses about why viewers may respond.
- **Content idea:** a practical, original adaptation suitable for a beginner tech creator.
- **Source:** direct link to the original video/Reel, plus a supporting evidence link when useful.

## How examples are selected
Choose the **best three overall**, ideally one from each platform format. Rank them by relevance to tech audiences, recency, useful evidence, clarity of presentation, originality, and how realistically a beginner could adapt the idea. Do not call a single high-view post a “trend” without broader evidence. Public engagement counts are signals, not proof of quality or causation.

If a direct original post or reliable metrics cannot be verified, say so rather than guessing. A missing metric is better than a fabricated one.

## Beginner-to-advanced learning path
- **Beginner:** explain one tech concept simply; record a screen demo; use a clear opening, clean audio, and basic captions.
- **Intermediate:** make short tutorials, tool comparisons, project walkthroughs, and multi-part explainers; test different hooks.
- **Advanced:** build recurring series, analyse audience retention and saves/shares where available, compare performance across formats, and develop an original point of view.
